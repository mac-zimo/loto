# Règles de travail
- Ne traite qu'UNE tâche de PLAN.md à la fois, puis arrête-toi.
- Découpe le code selon les responsabilités et la cohésion, pas selon une limite arbitraire de lignes.
- Un fichier qui mélange plusieurs responsabilités ou devient difficile à comprendre, tester ou modifier doit être scindé.
- Évite les fichiers excessivement volumineux ; au-delà d’environ 400–500 lignes, évalue explicitement si une séparation améliore réellement la conception.
- Pour modifier un fichier existant, utilise des éditions ciblées, jamais une réécriture complète.
- Ne lis que les fichiers nécessaires à la tâche en cours.
